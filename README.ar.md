# مهام · Mahamm

**كل وظائف المودل ومواعيد تسليمها في تقرير واحد.**

برنامج للحاسوب (نافذة وطرفية) وإضافة للمتصفح، بالعربية والإنجليزية، ويعمل على ويندوز وماك ولينكس، وعلى كروم وإيدج وفايرفوكس.

[English](README.md)

صُمم لكلية عزرائيلي للهندسة في القدس (`moodle.jce.ac.il`)، ويعمل مع أي موقع مودل مفعَّل فيه تطبيق المودل للهاتف.

## ماذا يقدّم

- كل الوظائف والاختبارات في الفصل الذي تختاره، مرتبة حسب أقرب موعد، مع تمييز المتأخرة.
- حالة كل وظيفة من المودل نفسه: مسلّمة، أو مسودة، أو متأخرة وما زال التسليم مفتوحًا، أو أُغلقت. وتظهر العلامة عند رصدها.
- وصف الوظيفة وأسماء ملفات التعليمات المرفقة بها. ومع خيار `--download-files` تُحفظ الملفات بجانب التقرير.
- اسم المساق دائمًا بالشكل **الاسم العبري - الاسم بلغتك**، مثل:
  - `תיכון מונחה עצמים - تصميم البرمجيات الكائنية`
  - `תיכון מונחה עצמים - Object-Oriented Design`
- التقرير بصيغة **PDF أو HTML أو Markdown أو JSON**، ويُحفظ في المكان الذي تختاره.
- تنبيه على مواعيد الساعة 00:00: موعد يوم الاثنين عند 00:00 يعني **نهاية يوم الأحد**، والتقرير يكتب ذلك بجانب كل موعد.
- في الإضافة فقط: رقم على الأيقونة بعدد الوظائف المطلوبة (أحمر إذا وُجدت وظيفة متأخرة)، وتذكير قبل كل موعد بيوم وبثلاث ساعات.

## برنامج الحاسوب

### التثبيت

افتح **[آخر إصدار](https://github.com/ahmad-salman322/mahamm/releases/latest)** وانزل إلى قسم **Assets**. نزّل **ملفًا واحدًا فقط** يناسب جهازك. لا تحتاج إلى أي برنامج آخر.

| جهازك | نزّل هذا الملف |
|---|---|
| ويندوز | `mahamm-windows-x64.exe` |
| ماك بمعالج آبل (M1 أو M2 أو M3 أو M4…) | `mahamm-macos-arm64` |
| ماك بمعالج إنتل | `mahamm-macos-x64` |
| لينكس (أغلب الحواسيب) | `mahamm-linux-x64` |
| لينكس على معالج ARM | `mahamm-linux-arm64` |

> لا تعرف نوع جهاز الماك؟ من قائمة آبل اختر **حول هذا الماك**. إذا كُتب فيها "Apple M…" فنزّل ملف `arm64`، وإذا كُتب "Intel" فنزّل ملف `x64`.
>
> الملفان المكتوب عليهما "Source code" هما الشيفرة المصدرية وليسا البرنامج، فلا تنزّلهما.

#### ويندوز

١. انقر مرتين على `mahamm-windows-x64.exe`.

٢. قد تظهر رسالة **"Windows protected your PC"** لأن البرنامج غير موقّع بشهادة مدفوعة. اضغط **More info** ثم **Run anyway**. هذا يحدث في المرة الأولى فقط.

٣. تُفتح نافذة سوداء ثم صفحة في المتصفح. **أبقِ النافذة السوداء مفتوحة** طوال استخدام البرنامج.

لاستخدام أوامر الطرفية افتح PowerShell في مجلد الملف واكتب مثلًا:

```powershell
.\mahamm-windows-x64.exe report
```

ويمكنك تغيير اسم الملف إلى `mahamm.exe` ليصبح أقصر.

#### ماك

افتح برنامج **Terminal** واكتب هذه الأوامر، واستبدل `arm64` بـ `x64` إذا كان جهازك بمعالج إنتل:

```sh
cd ~/Downloads
chmod +x mahamm-macos-arm64
xattr -d com.apple.quarantine mahamm-macos-arm64
./mahamm-macos-arm64
```

- الأمر `chmod +x` يجعل الملف قابلًا للتشغيل.
- الأمر `xattr` يزيل علامة "نُزّل من الإنترنت"، فلا يقول الماك إنه لا يستطيع التحقق من المطوّر.
- إذا بقي الماك يمنعه: افتح **إعدادات النظام** ثم **الخصوصية والأمان**، وانزل للأسفل واضغط **فتح على أي حال**، ثم شغّله من جديد.

#### لينكس

```sh
cd ~/Downloads
chmod +x mahamm-linux-x64
./mahamm-linux-x64
```

وإذا أردت أن تكتب `mahamm` فقط من أي مكان:

```sh
mkdir -p ~/.local/bin && mv mahamm-linux-x64 ~/.local/bin/mahamm
```

#### بواسطة Node.js (أي نظام)

إذا كان عندك Node.js بإصدار 22 أو أحدث:

```sh
npm install -g github:ahmad-salman322/mahamm
mahamm
```

### الاستخدام من النافذة

شغّل البرنامج (نقرتان على ويندوز، أو الأمر `./mahamm-…` على ماك ولينكس)، فتُفتح صفحة في المتصفح:

١. اضغط **تسجيل الدخول للمودل**، فتُفتح نافذة متصفح منفصلة على صفحة دخول الكلية. سجّل الدخول كالمعتاد، وتُغلق النافذة وحدها بعد ذلك.

٢. اختر الفصل واللغة ونوع الملف ومكان الحفظ، ثم اضغط **أنشئ التقرير**. ستظهر معاينة للتقرير بجانب الخيارات.

٣. عند الانتهاء أغلق تبويب المتصفح، فيتوقف البرنامج وحده بعد دقيقة تقريبًا. أو اضغط `Ctrl+C` في نافذته.

إذا لم تُفتح الصفحة وحدها، انظر في نافذة البرنامج: ستجد عنوانًا يبدأ بـ `http://127.0.0.1:` فانسخه إلى المتصفح.

### الاستخدام من الطرفية

```sh
mahamm login                          # تسجيل الدخول
mahamm semesters                      # قائمة فصولك
mahamm list                           # الوظائف المطلوبة في الطرفية
mahamm report                         # تقرير PDF لآخر فصل في مجلد المستندات
mahamm report -l ar -o ~/Desktop      # تقرير بالعربية على سطح المكتب
mahamm report -s 2026-2 -f md -o ./tasks.md
mahamm report --pending-only --download-files --open
mahamm report -o ~/Desktop -n "وظائفي {date}"   # اختيار اسم الملف
mahamm --help
```

| الخيار | معناه |
|---|---|
| `-s` | الفصل: `latest` (آخر فصل، وهو الافتراضي) أو `all` أو رمز من `mahamm semesters` |
| `-l` | لغة التقرير: `ar` أو `en` |
| `-f` | نوع الملف: `pdf` أو `html` أو `md` أو `json` |
| `-o` | ملف أو مجلد للحفظ، ويُنشأ المجلد إذا لم يكن موجودًا |
| `-n` | اسم الملف، ويمكن أن يحتوي `{semester}` و `{date}` و `{lang}`. يُضاف امتداد الملف تلقائيًا |
| `--pending-only` | الوظائف المطلوبة فقط |
| `--materials` | أضف الملفات والروابط التي تبدو كوظائف وليس لها صندوق تسليم |
| `--download-files` | نزّل ملفات التعليمات بجانب التقرير |
| `--open` | افتح التقرير بعد إنشائه |

لإنشاء ملف PDF يستخدم البرنامج في الخلفية متصفحًا مثبتًا عندك: كروم أو إيدج أو كروميوم أو بريف أو فايرفوكس.

## إضافة المتصفح

الإضافة ليست في متجر كروم أو فايرفوكس بعد، لذلك تُثبَّت يدويًا. الأمر يأخذ دقيقة.

**كروم وإيدج وبريف:**

١. من [آخر إصدار](https://github.com/ahmad-salman322/mahamm/releases/latest) نزّل الملف `mahamm-extension-chrome-<الإصدار>.zip`.

٢. فك ضغطه (على ويندوز: زر الفأرة الأيمن ثم **Extract All**، وعلى ماك: نقرتان). ستحصل على مجلد بداخله ملف `manifest.json`.

٣. انقل المجلد إلى مكان دائم مثل المستندات. **لا تحذفه لاحقًا** وإلا توقفت الإضافة.

٤. افتح `chrome://extensions` (في إيدج: `edge://extensions`، وفي بريف: `brave://extensions`).

٥. فعّل **وضع المطوّر** (أعلى اليمين في كروم، وعلى الجانب في إيدج).

٦. اضغط **تحميل إضافة غير مضغوطة** واختر المجلد الذي **يحتوي ملف `manifest.json` مباشرة**. إذا ظهرت رسالة أن ملف البيان مفقود فأنت اخترت المجلد الذي فوقه.

٧. اضغط أيقونة القطعة 🧩 في شريط الأدوات وثبّت **Mahamm**.

**فايرفوكس:**

فايرفوكس يحتفظ بالإضافات المثبّتة يدويًا حتى إعادة تشغيله فقط. إلى أن تُنشر في متجر موزيلا:

١. نزّل `mahamm-extension-firefox-<الإصدار>.zip` وفك ضغطه.

٢. افتح `about:debugging`، ثم **هذا الفايرفوكس**، ثم **تحميل إضافة مؤقتة**.

٣. اختر ملف `manifest.json` من داخل المجلد.

بعد التثبيت اضغط الأيقونة ثم **تسجيل الدخول للمودل**. يُفتح تبويب على صفحة دخول الكلية ويُغلق وحده بعد الدخول. تتحدث القائمة كل ساعة.

زر **التقرير الكامل** يفتح صفحة فيها:
- طباعة أو حفظ PDF
- تنزيل HTML أو Markdown أو JSON، مع اختيار مكان الحفظ

في الإعدادات (⚙) يوجد **مفتاح لبرنامج الحاسوب**. بهذا الأمر يسجّل البرنامج الدخول دون فتح متصفح:

```sh
mahamm login --token <المفتاح>
```

## حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| صفحة الإصدارات ليس فيها ملفات البرنامج، فقط "Source code" | لم يُبنَ إصدار بعد. اسأل صاحب المشروع، أو استخدم طريقة Node.js أعلاه. |
| ويندوز: رسالة "Windows protected your PC" | اضغط **More info** ثم **Run anyway**. |
| ويندوز: النافذة السوداء تُفتح وتُغلق فورًا | افتح PowerShell في المجلد وشغّل `.\mahamm-windows-x64.exe` لترى رسالة الخطأ، ثم أبلغ عن المشكلة. |
| ماك: "لا يمكن فتحه لأنه لا يمكن التحقق من المطوّر" أو "الملف تالف" | نفّذ أمر `xattr` المذكور في خطوات الماك. |
| ماك أو لينكس: `permission denied` | نفّذ أمر `chmod +x` على الملف أولًا. |
| ماك: `bad CPU type in executable` | نزّلت الملف الخطأ. ملف `arm64` لمعالجات آبل، وملف `x64` لمعالجات إنتل. |
| لينكس: النقر المزدوج لا يفعل شيئًا | شغّله من الطرفية: `./mahamm-linux-x64` |
| نافذة الدخول لا تُفتح، أو لا تُغلق بعد الدخول | استخدم `mahamm login --paste` واتبع الخطوات. |
| رسالة "No supported browser found" | ثبّت كروم أو إيدج أو كروميوم أو بريف أو فايرفوكس. وللدخول بدون متصفح استخدم `mahamm login --paste`، وللتقرير اختر HTML أو Markdown بدل PDF. |
| مساق يظهر باسمه العبري فقط | لا توجد له ترجمة بعد. انظر قسم ترجمة أسماء المساقات. |
| كروم: ملف البيان مفقود أو غير مقروء | اختر المجلد الذي يحتوي `manifest.json` مباشرة. |

## الإبلاغ عن مشكلة

استخدم **الإبلاغ عن مشكلة**: زر في النافذة، أو رابط أسفل نافذة الإضافة، أو هذا الأمر في الطرفية:

```sh
mahamm bug
```

يفتح نموذجًا على GitHub فيه رقم الإصدار والنظام والمتصفح وآخر رسالة خطأ، معبّأة مسبقًا. لا يُضاف مفتاح المودل ولا كلمة السر ولا اسمك ولا وظائفك، وترى كل شيء قبل الإرسال. تحتاج حسابًا مجانيًا على GitHub للإرسال.

للأفكار الجديدة وترجمات المساقات الناقصة توجد نماذج خاصة في [صفحة المشاكل](https://github.com/ahmad-salman322/mahamm/issues/new/choose).

## تسجيل الدخول والخصوصية

يسجّل البرنامج الدخول بنفس طريقة تطبيق المودل الرسمي للهاتف: تدخل على صفحة الكلية الحقيقية، فيعطي المودل البرنامج مفتاح وصول خاصًا بك. **كلمة السر لا يراها البرنامج ولا يحفظها أبدًا.**

يُحفظ المفتاح في ملف لا يقرؤه غيرك:

- ويندوز: `%APPDATA%\mahamm`
- ماك: `~/Library/Application Support/mahamm`
- لينكس: `~/.config/mahamm`

أما الإضافة فتحفظه في تخزينها المحلي. ولا يُرسل أي شيء إلى أي جهة غير موقع المودل.

لإلغاء المفتاح: من المودل افتح **التفضيلات**، ثم **مفاتيح الأمان**، وأعد تعيين مفتاح "Moodle mobile web service". ولحذفه من جهازك:

```sh
mahamm logout
```

إذا لم تعمل نافذة الدخول التلقائية، استخدم هذا الأمر واتبع الخطوات:

```sh
mahamm login --paste
```

## ترجمة أسماء المساقات

الترجمات موجودة في الملف [`core/translations.js`](core/translations.js). إذا لم يكن للمساق ترجمة يظهر اسمه العبري فقط، والأمر `mahamm report` يخبرك بالمساقات الناقصة.

لإضافة ترجمة للجميع: أضف سطرًا في الملف وافتح طلب دمج (Pull Request) 🙏

ولإضافتها لنفسك فقط: أنشئ ملف `translations.json` في مجلد الإعدادات المذكور أعلاه:

```json
{ "שם הקורס בעברית": { "en": "Course name", "ar": "اسم المساق" } }
```
